# Most Autonomii — instalacja APK (Android)

**Aplikacja:** Most Autonomii
**Pakiet:** pl.haos.mostautonomii
**Plik:** dist/Most-Autonomii-debug.apk (debug, podpis Capacitor)

Bundluje lokalne pliki PWA (www/) — offline. Poll data/room.json włączony domyślnie.

## Instalacja na telefonie Adama

1. Pobierz Most-Autonomii-debug.apk (załącznik / Releases / dist/).
2. Włącz instalację z nieznanych źródeł: Ustawienia → Bezpieczeństwo/Aplikacje → Instaluj nieznane aplikacje → zezwól dla Chrome/Pliki/Telegram.
3. Otwórz APK → Zainstaluj.
4. Przy Play Protect wybierz Zainstaluj mimo to.
5. Uruchom ikonę Most Autonomii.

## Uwagi

- Debug APK — tylko do testów, nie do Play Store.
- Przy konflikcie odinstaluj poprzednią wersję o tym samym applicationId.
- Alternatywa: PWA z GitHub Pages → Dodaj do ekranu głównego.

Szczegóły rebuild: README (sekcja Android / Capacitor).
